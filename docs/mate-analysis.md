**FAQ에서 확정된 사실** (추정 → 공식으로 승격):
- **AI 도구 사용 자체는 패널티 아님** — 단 "사람이 직접 쓴 문장이 아닌 AI가 기계적으로 생성·요약한 콘텐츠"는 걸러질 가능성 (최종 검토·편집으로 경험·지식을 녹이라는 조건부)
- **C-rank 공식 인정** — "특정 주제를 꾸준히 쓴 채널은 더 자주 인용될 수 있다" (기존 '추정' 딱지 해제)
- **검색 상위 노출 글이 인용 확률 높다** (공식) — seonews의 "49%는 Top10 밖"과 공존: 상위 노출이 유리하되 필수는 아님
- **최신성은 트렌드 주제만 우대** — 불변 정보는 깊이·구조가 더 중요 (우리 스나이핑 전략은 트렌드형에 유효)
- 이미지 핵심 정보는 **텍스트로도 병기**해야 인용에 유리

**스팸 필터의 실제 기준** (3편 — 우리 리스크의 공식 정의):
- 저품질 대량 생성 = "동일·유사 템플릿으로 무의미하게 대량 발행". **"AI나 자동화 프로그램 활용 여부만으로는 판단하지 않는다"** — 자동화 자체가 아니라 무의미·반복이 기준 (우리 일 1~2건 + 품질 게이트 + 주제별 상이한 내용 설계는 이 기준에 부합)
- 스크래핑 = 타 사이트 내용을 "복사 또는 기계적으로 변형해 거의 그대로 게시" — 리서치 소스 문장 복사 금지, 반드시 재구성
- 키워드 반복·남용, 낚시성(제목-본문 불일치)도 명시적 스팸 유형

**셀프 체크 5항목 + Good/Bad 사례가 그리는 이상형** — ①독자·상황(TPO) 정의 ②절차·시행착오의 구체 서술 ③대안 비교 + 상황별 추천("커플에겐 A, 가족에겐 B") ④실사용 결과·직접 측정 수치 ⑤맥락 맞는 멀티미디어+텍스트 병기.
Bad case로 **"순위만 나열한 글", "스펙시트 그대로 옮긴 글"이 명시**됨.

**⚠️ 우리 전략과의 긴장 (정직한 평가)**: 공식 이상형은 '직접 경험·측정'이고, 우리의 정보 정리형은 Bad case("순위 나열")에 가까워질 위험이 있다. 그럼에도 영화구름(순위 나열+표)이 실제 인용 중인 것은 **해당 쿼리에 공급이 없기 때문** — 공급 공백에서는 정리형도 이긴다. 대응: ① 자동 생성 가능한 공식 요소(TPO 정의, 상황별 추천, 대안 비교, 객관 근거 인용)를 템플릿에 최대 반영 ② '직접 측정' 요소는 자동화 불가 — 한계로 인정하고, 발행 60일 후 인용 0이면 사용자 경험 재료 옵션 재검토 (pending.md 조건과 연결) ③ 발행 빈도·품질 게이트가 스팸 기준(무의미 대량)과의 거리를 유지.

## 직접 관찰 ① — AI 브리핑은 아무 쿼리에나 뜨지 않는다

같은 날 세 쿼리를 실계정으로 검색한 결과 (2026-08-17, 스크린샷 보존):

| 쿼리 | AI 브리핑 | 상단을 차지한 것 |
|------|-----------|------------------|
| 넷플릭스 요금제 | ❌ 없음 | 파워링크 광고 |
| 소상공인 정책자금 신청 방법 | ❌ 없음 | 대출 광고 |
| **넷플릭스 이번주 순위** | ✅ **최상단 노출** | AI 브리핑 (요약+표+후속질문창) |

**함의 (C1 키워드 전략의 1차 필터)**: 검색량·문서수가 아무리 좋아도 **그 쿼리에 AI 브리핑이 안 뜨면 인용 기회 자체가 없다.** 광고 단가가 높은 상업성 쿼리는 광고가 상단을 점령하고 브리핑이 밀리거나 없다. → 주제 선정 시 "브리핑이 뜨는 쿼리인가"를 확인하는 신호를 C1에 추가해야 한다 (C6 관찰 모듈의 핵심 임무로 편입).

## 직접 관찰 ② — 인용 독점 사례: 블로그 "영화구름" (케이스 스터디)

"넷플릭스 이번주 순위" AI 브리핑의 **출처 2건이 모두 한 블로그** (영화구름, blog.naver.com/moviecloud_)의 주간 시리즈 글이다.

**인용된 글의 구조** (2026-06-4주차 편, 원문 확인):
- 제목: "2026년 6월 4주차 주간 넷플릭스 글로벌 영화 및 시리즈 순위를 통해 알아보는 넷플릭스 추천작 10선" — 기간 명시 + 검색 의도 정합 + 구체적
- 전용 카테고리 "주간 넷플릭스 순위"에 매주 발행 (시리즈 반복 = C-rank 전문성)
- 본문: 짧은 인트로 → **집계 기준 명시**("뷰 수 기준") → 5위→1위 역순 → 작품마다 **동일 스키마의 표**(공개일/국가/장르/감독/출연/러닝타임/시청등급/로튼토마토 점수/주간 뷰 수) → 시놉시스 1문단. 영화 5편 + 시리즈 5편
- 성격: **경험담 0%, 공개 데이터(넷플릭스 공식 Top10 + 로튼토마토)를 구조화해 재정리한 순수 정보형 글**

**AI 브리핑이 이 글을 다루는 방식**: 표를 그대로 재구성하고, 작품별 요약을 불릿으로 발췌하며, 출처 각주를 단다. 즉 **구조화가 잘 된 글일수록 브리핑이 뜯어 쓰기 좋다** (리드젠랩 AEO 가이드의 "표·목록·위계" 원칙과 일치하는 실증).

**결정적 디테일**: 이 블로그는 6월 말 이후 발행이 끊겼고, AI 브리핑이 "8월 기준 순위는 검색 결과에 없어 6월 자료로 답한다"고 **사과까지 하면서** 낡은 글을 인용 중이다. → **신선한 글이 올라오면 즉시 인용을 가져올 수 있는 공백 상태.**

## 실행 함의 (파이프라인 반영 목록)

1. **C2 글 템플릿의 원형 확보** — "고정 스키마 표 + 기간 명시 + 집계 기준 명시 + 항목별 요약"의 시리즈형 정보 글. 경험담 없이도 인용됨이 실증됐다 (우리 "정보 정리·분석형만" 전략의 직접 근거).
2. **인용 공백 스나이핑 전략** — C1/C6에서 "브리핑이 뜨는데 출처가 낡은(N주 이상 미갱신) 쿼리"를 탐지하면 그게 최우선 주제다. 영화구름 공백이 첫 실전 후보: 넷플릭스 주간 순위 시리즈를 우리가 이어서 발행.
3. **C1 키워드 신호 추가** — 골든 점수·LLM 채점에 더해 "AI 브리핑 존재 여부 + 출처 신선도"를 확인 (검색 1회로 관찰 가능, 쿼리 예산 내).
4. **주간 시리즈 = 반복 가능한 인용 자산** — 일회성 글보다 같은 카테고리에 매주 쌓이는 시리즈가 C-rank(전문성)와 신선도를 동시에 챙긴다.

## 프로필 인용수 위젯 — 실측 상세 (2026-08-17, 본인 계정 DOM 확인)

**위치·셀렉터**: 블로그 프로필 위젯 `iframe#mainFrame` 내 `span.nmate_count` (예: "100 미만 인용").

**툴팁 원문에서 확정된 사실**:
1. **세 가지 수치 제공** — 누적 인용수 / 당월 인용수 / **"N-2월 인용수 (N월 대상자 선정 기준)"**
2. **⭐ 선정은 2개월 전 월간 인용수 기준** — "6월 인용수 (8월 대상자 선정 기준)" 원문 확인.
   즉 이번 달 인용이 선정에 반영되기까지 2개월 시차. 지금(8월) 발행 시작 → 첫 인용이 9~10월에
   발생한다면 → 반영되는 선정은 **11~12월**. 기대 시점 관리의 근거.
3. **매일 업데이트** (공식 문구), 2026년 1월부터 집계, **본인에게만 공개**
4. **100 미만은 정확한 수 미표시** ("100 미만"으로 뭉뚱그림) — 0→1→10 진행을 이 지표로는
   볼 수 없다. **초기 국면의 1차 신호는 글별 검색 관찰(ai_cited)로 승격** (C4 설계 변경)
5. 메이트 선정자는 인용수가 모두에게 공개 (Threads 복수 소스) — **C7에서 선정자 프로필을
   표본 수집하면 선정 커트라인(월 몇 인용이면 3,000명 안인가)을 추정 가능**

**크리에이터 어드바이저** (creator-advisor.naver.com/naver_blog/<id>, 세션 접근 확인):
조회수·검색 유입수·방문·순방문·유입검색어 순위·게시글별 분석 제공 (실시간+일별).
